Install AceTVET App

Muat turun AceTVET sebagai aplikasi di peranti anda

🤖

Android (Chrome)

  1. Buka Chrome dan layari ke AceTVET
  2. Klik menu "⋮" di kanan atas
  3. Pilih "Tambah ke Skrin Utama" atau "Install App"
  4. Klik "Tambah" untuk mengesahkan
🍎

iOS (Safari)

  1. Buka Safari dan layari ke AceTVET
  2. Klik butang "Share" (⎙) di bawah
  3. Scroll ke bawah dan pilih "Tambah ke Skrin Utama"
  4. Klik "Tambah" untuk mengesahkan
💻

Desktop (Chrome/Edge)

  1. Buka Chrome atau Edge dan layari ke AceTVET
  2. Lihat ikon "Install" di bar alamat
  3. Klik ikon install dan pilih "Install"
  4. Aplikasi akan ditambah ke desktop anda
